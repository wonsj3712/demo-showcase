# Demo Showcase

Sionic AI 데모 웹 앱 모음. 고객 미팅이나 팀 내부에서 빠르게 데모 화면을 확인할 수 있도록 GitHub Pages로 호스팅합니다.

**데모 목록 페이지**: https://wonsj3712.github.io/demo-showcase/

## Demos

| 데모 | 설명 | URL |
|------|------|-----|
| EPC Email Issue Management | EPC 프로젝트 이메일 기반 이슈 추적/분류/대시보드 | [바로가기](https://wonsj3712.github.io/demo-showcase/epc-demo/) |

## 데모 추가 방법

1. 데모 프로젝트에서 `npm run build`
2. `dist/` 내용물을 이 레포의 `{데모폴더명}/`에 복사
3. 루트 `index.html`에 카드 추가, 이 README 표에도 추가
4. 커밋 & 푸시 → GitHub Pages 자동 반영
